# humanizer-uk: редактура українського тексту для AI-агентів

> Прибирає з українського тексту ознаки ШІ й не змінює того, що в ньому сказано: ШІ-звороти, русизми, кальки з польської й англійської, канцелярит, пасив, розмітку чату й типографіку. Розрізняє регістр і канал: пост, лист, сайт, довідка, наукова чи юридична мова правляться по-різному. Ставиться однією командою в будь-який агент зі скілами: Claude Code, Codex, Cursor, GitHub Copilot, Cline, Gemini CLI, Windsurf, OpenCode і ще понад 70 ([список](https://github.com/vercel-labs/skills/blob/main/docs/agents.md)).

**Було:**

> Шановний пане Олег! Надсилаю вам приведений нижче перелік документів по питанню оренди. В даний час договір підписується директором, тому прошу підтвердити отримання на протязі тижня.

**Стало:**

> Шановний пане Олеже! Надсилаю вам наведений нижче перелік документів щодо оренди. Зараз договір підписує директор, тому прошу підтвердити отримання протягом тижня.

П’ять правок: кличний відмінок, два русизми («приведений», «на протязі»), канцелярська зв’язка («по питанню», «в даний час») і пасив. Зміст, строк і тон листа ті самі, нового нічого. На 28 тестових текстах скіл не змінив жодного числа, лишив емодзі й жирні заголовки там, де вони частина формату, а в 6 людських уривках виправив лише одну чужу літеру ([перевірка](#перевірка)).

Скіл редагує для людини, а не для детектора. GPTZero, Copyleaks і подібні сервіси можуть і далі позначати результат як ШІ: обходити їх скіл не намагається, і ми цього не перевіряємо.

## Встановлення

Одна команда для будь-якого з 80 агентів; CLI сам знайде встановлені й спитає, куди ставити. Інших скілів не потрібно:

```bash
npx skills add panchlab/humanizer-uk
```

У Claude Code можна плагіном, тоді оновлення приходять через `/plugin`:

```text
/plugin marketplace add panchlab/humanizer-uk
/plugin install humanizer-uk@humanizer-uk
```

Claude.ai і Claude Desktop: завантажте репозиторій як ZIP і додайте як скіл у налаштуваннях.

## Як користуватися

- «Зроби текст живим», «вичитай стиль», «прибери ШІ-стиль» (підійде й «олюдни»): редактура, повертається виправлений текст.
- «Що тут видає ШІ?»: аудит, список маркерів без переписування.
- «Прибери лише канцелярит», «виправ лапки»: точкова правка.
- Дайте свої тексти як зразок: заміни підлаштуються під ваш ритм і пунктуацію.

## Що він виправляє

- **Загальні патерни ШІ-тексту** ([§1–§26](references/patterns.md)): «не X, а Y», рубані фрагменти, нав’язані трійки, тире-з’єднувачі, роздута значущість, жирний як прикраса, залишки чату.
- **ШІ-звороти:** «зануртеся у світ…», «не просто…, а…» і «X, а не Y» як підсумок, заголовок «Висновок» над переказом статті, блок «Чому обирають нас» без фактів. У постах, розсилках і прес-релізах також м’які штампи: «найкращі ціни сезону», «ідеальне місце для…», «ми з радістю…».
- **Розмітка чату:** жирний, маркдаун-заголовки, емодзі й службові рядки шаблону прибираються лише там, де канал їх не покаже (у листі зірочки зникають, у Telegram лишаються жирним); структура сайту, довідки й постів лишається.
- **Русизми:** «приймати участь», «на протязі», «задача» в значенні «завдання», дієприкметники на -учий/-ючий.
- **Кальки з польської:** «забронювати візит», «під адресою», «в годинах 9–17», «в уряді воєводства», «надгодини». Для українців у Польщі й перекладів із польської; реалії спільноти на кшталт «карта побиту» чи «брутто» без прохання не чіпає.
- **Кальки з англійської:** «на щоденній основі», «адресувати проблему», «реальний вплив», а в перекладах — «Ключові моменти» і «ви можете…» на кожному кроці. IT-жаргон у текстах для фахівців лишається.
- **Канцелярит і пасив:** «здійснюємо доставку», «виконуємо ремонт», «з метою», «лист підписується директором»; у документі й науці одна канцелярська зв’язка на абзац — норма жанру.
- **Типографіка:** лапки «…», апостроф ’, тире за правописом замість дефіса, діапазони «9:00–18:00», нерозривні пробіли для сайту й друку, чужі літери в українських словах.

Регістр має значення: у науковому тексті пасив і «у зв’язку з цим» лишаються, у юридичному правляться лише явні помилки, у діловому листі формули ввічливості не чіпаються, репліки персонажів у художньому тексті теж.

## Чого скіл не робить

- Не додає фактів, чисел, імен і деталей «для живості».
- Не викидає функцію разом із водою: заклик, пропозиція, строк, ціна й контакт лишаються.
- Не перекладає; переклад робиться окремо, скіл вичитує результат.
- Не чіпає людського тексту без прохання: якщо текст ваш, правляться лише явні помилки.
- Не обходить детектори ШІ, не вставляє опечаток і невидимих символів.

## Перевірка

Детерміновані перевірки без моделі й залежностей, лише Python 3.9+:

```bash
python evals/run_evals.py
```

Раннер звіряє [еталонні правки](evals/evals.json): числа й обов’язкові фрагменти на місці, немає російських літер, прямих лапок і апострофів, тире-з’єднувачів після жирної назви, тире частіше, ніж у кожному четвертому реченні, розмітки не за каналом і заборонених зворотів. Виходи моделі перевіряються через `--outputs`.

Сліпий тест із суддями-моделями (жовтень 2026): 28 текстів у 13 жанрах (18 згенеровано чотирма моделями Claude, 10 з evals), вісім систем на одній моделі, двоє суддів (Claude і GPT), порядок версій випадковий. Версія 1.3 за сумою суддів була першою з восьми і губила факти найрідше: у 5–6 текстах проти 13–14 у моделі без скіла; різниця з найближчими конкурентами в межах шуму, перевага над моделлю без скіла значуща.

Людський сліпий тест (жовтень 2026): 8 текстів (по два від Claude і GPT, переклади з польської та англійської, два тексти польських установ для українців), чотири системи на одній моделі, порядок версій випадковий. Із чотирьох запрошених редакторів відповідь надіслала одна людина, носій мови. Найкраще середнє місце з чотирьох мала версія 1.3 (1,94; тоді вона працювала поверх humanizer), далі 1.7.0 (2,56), модель без скіла та інший скіл для української (по 2,75). На текстах моделей 1.3 щоразу була першою або ділила перше місце; на обох перекладах першим був інший скіл, а 1.7.0 посіла останнє місце.

У 1.7.0 людина позначила дві зміни змісту: з поста зник оцінний зачин і з’явилася деталь, якої в тексті не було, а в перекладі з польської «публічний сектор» став «державним». Версія 1.7.1 виправляє обидві, для кожної додано кейс в evals. Судді-моделі на тих самих 8 текстах погодилися з людиною щодо того, яка з двох версій краща, у 52% пар (Claude Opus, рівень випадковості) і 64% (GPT), тож результатові суддів вище не варто довіряти беззастережно. Відповідь лише одна, тому висновки попередні; 1.7.1 люди ще не оцінювали.

## Для звірки

Правила й приклади написано власноруч, словникові статті не копіювалися. Спірні випадки звіряйте з:

- [Український правопис 2019](https://mon.gov.ua/static-objects/mon/sites/1/zagalna%20serednya/Pravopys.2019/ukr.pravopys-2019.pdf) (МОН України)
- Б. Антоненко-Давидович, «Як ми говоримо»
- О. Пономарів, «Культура слова: мовностилістичні поради»
- С. Караванський, «Російсько-український словник складної лексики»
- [Правила української мови в LanguageTool](https://github.com/languagetool-org/languagetool/tree/master/languagetool-language-modules/uk/src/main/resources/org/languagetool/rules/uk) (LGPL 2.1)
